# The Qt every build carries (A6.2): the parts of PySide6 MusiKata uses, and nothing else of it.
# scripts/qt_trim.py removes what isn't here from the PySide6 a build installed, before it packs it,
# and stops when a line names nothing there, a QML module kept needs one left out, or a library kept
# links one left out. Each build's start test then plays a file in the packed app.
#
#   module NAME      a Qt module: its library (libQt6NAME.so.6, Qt6NAME.dll, QtNAME.framework) and
#                    its Python binding (QtNAME)
#   plugin TYPE/NAME a plugin, named without "lib" and its extension
#   qml PATH         a QML module: a folder of Qt's qml folder with a qmldir, without the modules
#                    below it
#   keep PATTERN     any other path in the PySide6 folder (a shell pattern, `*` within a part)
#
# A line ending in platforms (linux, windows, macos) is for those only. A part joins with the code
# that uses it; Qt Multimedia's FFmpeg plugin and libraries never do, as PyAV carries the FFmpeg
# that decodes (A4.1).
