# A6. Packaging and platforms

A6.1. **One Python, one Qt, three platforms.** `packaging/versions.env` pins the Python (a
python-build-standalone build, by version and SHA-256 per platform), PySide6, Mutagen, NumPy, the
platform modules of A4.5, and every build tool. Each pin moves only to a release at least 14 days
old, as in AppKata, and only by a commit there.

A6.2. **PySide6 Essentials and Addons.** Qt Multimedia, which playback needs, is in
`PySide6-Addons`, which also carries large modules MusiKata doesn't use (WebEngine, 3D, Charts,
Graphs, Bluetooth and more). The builds install both, then remove the modules not on an allow
list in `packaging/qt-modules.txt` before packing, the way AppKata trims its AppImage. A test
starts the packed app and plays a file, so a module removed by mistake fails the build.

A6.3. **Linux: AppImage.** Built on Ubuntu 22.04 for its glibc, as AppKata's is, with the same
appimagetool and runtime pins. It carries Python, Qt, Qt Multimedia's FFmpeg libraries, and the
xcb libraries Qt needs; from the system it takes only what every desktop of R1.1 has (glibc,
OpenGL, PulseAudio or PipeWire's Pulse server, D-Bus, fonts). It installs itself into the app menu
on first start and updates itself from the project's releases.

A6.4. **Windows: Inno Setup,** per user by default, built under Wine in a container as AppKata's
is, with PyInstaller freezing the app. It registers the file kinds of R1.7 for "Open with" only.

A6.5. **macOS: an app bundle in a `.dmg`,** built on a macOS runner with PyInstaller, signed with
a Developer ID, notarized and stapled. The window uses the system's title-bar buttons over a
full-size content view (R6.4). The bundle declares the document kinds of R1.7.

A6.6. **Licenses.** Each build carries `LICENSE.txt` and `THIRD-PARTY-NOTICES.txt`: the licenses of
Python, Qt and PySide6 (LGPL-3.0), Qt's FFmpeg (LGPL-2.1), Mutagen (GPL-2.0-or-later), NumPy (BSD)
and the platform modules, generated by a script from the installed packages so it can't fall
behind.

A6.7. **The demo library.** Tests, the tour and the screenshots never use real music. A script
generates a demo library: short tones and noise encoded to each kind of R2.2 with FFmpeg, tagged
with the made-up artists and albums of the mockups, some of them deliberately wrong (missing
years, lower-case artists, odd genres, missing covers) so Needs attention and R3 have work to
show.
