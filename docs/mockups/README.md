# MusiKata mockups

```
docs/mockups/
  <screen>.png      the mockups: dark theme, 256-colour PNG, drawn at 1280 × 800, saved at 2560 × 1600
  src/render.py     draws them all (PySide6 offscreen and Pillow): python docs/mockups/src/render.py [filter …]
```

Dark is the design target (R6.2); light mockups come later. The colours are the design tokens of
R6.2, the artists, albums and songs are made up, and the album art is drawn from a seed, so
nothing here is anyone's real music or artwork. Screens are named by area: **X** = app-wide,
**L** = the library views (Folders is L04 to L08), **T** = tag tools, **P** = playlists, **G** = genres, **N** = Now
Playing, **S** = Settings, **M** = the mini player. Requirement numbers refer to [`../requirements/`](../requirements/README.md).

They are kept in step with the requirements ([process](../process/README.md#mockups-in-step-with-the-requirements)).
